# Vitor Tyso — Novo Luxo

Projeto independente da landing page atual, em HTML, CSS e JavaScript.

## Conteúdo

- Identidade editorial em preto e branco e imagens da campanha aprovada.
- Diagnóstico Distração Digital com as oito perguntas, pesos e fórmula do site original, consultado em 17/11/2026.
- IAT com as dez perguntas e pontuação de zero a vinte da landing page atual.
- Respostas salvas somente no navegador e relatórios em texto para download.
- Checkout Hotmart preservado do site atual.

## Publicação

Sirva a pasta dist com um servidor HTTP estático. O projeto não exige instalação ou build. Na Vercel, pode ser importado como projeto estático (Other), sem comando de build e com Output Directory dist.

A integração de captura de e-mail do diagnóstico original não foi transferida: esta versão mostra o resultado diretamente, sem enviar dados ao servidor anterior.

As projeções de tempo são simulações da fórmula original; a interface as identifica dessa maneira.
